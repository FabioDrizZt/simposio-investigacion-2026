## ⌨️ Atajos útiles durante la exposición

- **En la presentación (`/presentacion/`):**
  - `S`: abrir vista de orador (notas + siguiente diapositiva + reloj).
  - `T`: iniciar / pausar el cronómetro de 3:00 minutos del pitch (`R` para reiniciar).
  - `P`: pausar / reanudar animaciones continuas.
  - `F`: pantalla completa · `ESC` / `O`: vista general de diapositivas.
- **En el póster (`/poster/`):**
  - `F`: pantalla completa · `P`: pausar / reanudar el recorrido automático de pasos.
